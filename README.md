## 🛠️ How to use the Level Data

Each `.json` file represents a single level in the game. The game engine fetches these files directly from this repository at runtime. 

If you want to create your own levels:
1. Fork this repository.
2. Create a new `.json` file following the structure of the existing ones.
3. Test it locally or host it on your own GitHub Pages/raw link.
